# LocalTab-Scores

[English](README.md) · [LocalTab 编辑器](https://github.com/phageous01/LocalTab)

由 [phageous01](https://github.com/phageous01) 维护的公开 MusicXML 曲谱库。
每首曲子有固定的介绍页面，适合放在视频简介、音乐平台和个人页面中。
下载 MusicXML 后，可使用 LocalTab 或其他支持吉他/贝斯 TAB 的记谱软件打开。

## 下载和使用

1. 打开上方的 **曲谱页面** 查看说明，再打开其中的 MusicXML 文件。
2. 在 GitHub 文件页面点击 **Download raw file**。如果原始文件链接在浏览器中显示 XML，
   请另存为 `.musicxml` 文件，不要保存成网页。
3. 在 LocalTab 点击 **导入乐谱**，选择下载的文件。不同软件的排版和奏法显示可能略有差异。

GitHub 显示的是 XML 源文件，本身不提供交互记谱或播放。公开仓库不包含 MP3 和 LocalTab
同步 metadata；你可以在 LocalTab 中添加自己的录音并进行同步。

## 外部链接和更新方式

在各平台推荐使用单曲的 **曲谱页面地址**。以后更新乐谱或补充说明时可以继续沿用。
只要保留文件夹和文件名，MusicXML 的原始文件链接也保持不变。
`main` 下的链接总是指向最新版，旧版保留在 Git 历史中。
这个仓库为外部链接提供新的目标地址，不会自动修改其他平台上的个人资料或链接。

增加新曲时，在 `scores/<固定英文标识>/score.musicxml` 放置文件，添加该目录的 README，
并更新中英文曲谱目录。更新现有曲谱时，从 LocalTab 导出 MusicXML，替换对应文件，
再提交并推送。LocalTab 中的“保存”不会自动更新本仓库。
